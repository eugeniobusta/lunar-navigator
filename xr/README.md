# Lunar Landing Site Navigator: VR view

The 3D and VR part of the project, built with the Immersive Web SDK (IWSDK 1.1.0) and served at `/xr/`.
Everything about running it, the file map and testing on a Meta Quest 3 is in [docs/XR.md](../docs/XR.md).

Quick start, from the repository root: `make setup`, then `make xr-dev` and open https://localhost:8081.
